# ECA1204 – Antenna and Wave Propagation Lab Experiments

**Course Code:** ECA1204  
**Subject:** Antenna and Wave Propagation  
**Platform:** MATLAB  
**Branch:** Main

## About

This repository contains MATLAB-based laboratory experiments for the subject **Antenna and Wave Propagation**. It includes simulations, analysis, and evaluation of electromagnetic wave propagation and antenna-related characteristics.

## Experiments Included

| No. | Experiment Title | Tool |
|---|---|---|
| 1 | Simulation of EMI Sources and Interference Analysis | MATLAB |
| 2 | Shielding Effectiveness and EMC Compliance Analysis | MATLAB |
| 3 | Simulation of Ground Wave and Sky Wave Propagation | MATLAB |
| 4 | Simulation of Space Wave Propagation Characteristics | MATLAB |
| 5 | Simulation and Evaluation of Critical Frequency and MUF | MATLAB |
| 6 | Simulation and Evaluation of Virtual Height and Tropospheric Propagation | MATLAB |

## Software Requirements

- MATLAB
- Basic knowledge of Antenna and Wave Propagation
- MATLAB plotting and simulation tools

## Learning Outcomes

- Understand electromagnetic wave propagation.
- Analyze EMI and EMC characteristics.
- Simulate ground, sky, and space wave propagation.
- Calculate critical frequency and Maximum Usable Frequency (MUF).
- Evaluate virtual height and tropospheric propagation.

## Repository Structure

Each experiment is organized in a separate folder containing its MATLAB programs and related files.
